# Module herald-kmp-appsflyer

AppsFlyer's revenue events for shared Kotlin code. Make each one with the function named after its
class, such as `appsFlyerPurchaseEvent(…)`.

- On Android, they are herald-appsflyer's own classes.
- On iOS, the app's Swift turns them into herald-ios-appsflyer's (see RevenueTranslation.swift).
